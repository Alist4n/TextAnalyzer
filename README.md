# TextAnalyzer

Десктоп-программа для морфологического и синтаксического анализа русских текстов
и определения эмоций. Принимает один текст или набор текстов, формирует отчёт в
HTML, DOCX и JSON.

## Скачать

Готовая программа для Windows — в разделе [Releases](../../releases/latest): скачайте архив
`TextAnalyzer-…-windows.zip`, распакуйте и запустите `TextAnalyzer.exe`. Собирать ничего не нужно:
Python, модели и все библиотеки уже внутри, интернет для анализа не нужен. Словарь NRC EmoLex
в архив не входит (см. ниже) — его можно скачать из меню «Файл», а до этого работает ручной словарь.

### Словарь эмоций NRC EmoLex

Словарный метод использует **NRC Word-Emotion Association Lexicon (EmoLex)**, созданный
Saif M. Mohammad и Peter D. Turney в National Research Council Canada (NRC):
<https://saifmohammad.com/WebPages/NRC-Emotion-Lexicon.htm>. Это 14 тыс. английских слов, для которых
люди (краудсорсинг) отметили связь с эмоциями. Русские слова — машинный перевод Google Translate
(2022) из того же архива NRC.

Условия NRC: бесплатно **только для некоммерческого исследовательского и учебного** использования;
**данные нельзя распространять** — поэтому словарь не входит в программу, каждый скачивает его сам
скриптом `scripts/download_nrc_lexicon.py` (условия — в `models/nrc-emolex/README-NRC.txt`). Для
коммерческого использования нужна лицензия NRC (saif.mohammad@nrc-cnrc.gc.ca). В работах, где
используются результаты, нужно цитировать: Mohammad S. M., Turney P. D. *Crowdsourcing a
Word-Emotion Association Lexicon*. Computational Intelligence, 29(3): 436–465, 2013.

Как собирается русский словарь (`textanalyzer/nlp/nrc.py`):
- берутся пять эмоций, которые определяет и нейросеть: радость, грусть, удивление, страх, гнев
  (отвращение, доверие и ожидание из EmoLex не используются);
- перевод приводится к лемме pymorphy3; словосочетания и непереведённые слова пропускаются;
- если одной русской лемме соответствует несколько английских слов, вес эмоции — доля связанных
  с ней (радость ← joy, gladness, cheer: радость 1,0, удивление 1/3); связи слабее 0,5 и
  служебные слова («очень» ← sorely) отбрасываются как шум перевода.

Получается около 2400 лемм. Перевод местами ошибочен (adder «гадюка» → «сумматор»), а часть связей
неочевидна («больница» — грусть и страх); нет и некоторых частых слов («рад», «грустный», «бесит»).

### Выбор словаря эмоций

Словарей два, выбор — в окне («Словарь эмоций» под методом эмоций) или ключом `--lexicon`:

| Словарь | Ключ | Лемм | Особенности |
|---|---|---|---|
| NRC EmoLex | `--lexicon nrc` | ~2400 | больше охват, но и больше случайных связей; скачивается отдельно, лицензия NRC |
| Ручной (TextAnalyzer) | `--lexicon manual` | 649 | составлен вручную: только слова, явно выражающие эмоцию, вес 0–1 — насколько явно; входит в программу (`textanalyzer/nlp/data/lexicon_manual_ru.json`) |

По умолчанию — NRC EmoLex, если он скачан, иначе ручной словарь: так первый анализ в только что
полученной программе проходит без ошибки. Выбор в окне запоминается. Правила анализа — усилители, отрицания и глаголы
вроде «испытывать» — общие для обоих словарей, в `textanalyzer/nlp/data/lexicon_rules_ru.json`.
Каким словарём построен отчёт, написано в его разделе «Методика».

### Работа без интернета

Интернет нужен только для установки. Анализ и отчёты работают офлайн: spaCy и pymorphy3
устанавливаются как пакеты, словарь эмоций и модель эмоций читаются из `models/` только с диска
(`local_files_only`), в HTML-отчёте нет внешних скриптов, шрифтов и картинок. Тексты никуда не
отправляются. Это проверяет `tests/test_offline.py`: там сеть заблокирована и подсчитываются
попытки подключения.

Если папки `models/` нет, модель берётся из кэша HuggingFace (`%USERPROFILE%\.cache\huggingface`);
если нет и его, а сети тоже нет, анализ сразу останавливается с сообщением: скачать модель или
выбрать «Только словарь» (`--emotions lexicon`). Так же для словаря: если NRC EmoLex не скачан, анализ
останавливается с подсказкой скачать его (меню «Файл» или `download-nrc`), выбрать ручной словарь
(`--lexicon manual`) или «Только нейросеть» (`--emotions model`).

## Запуск

**Графический интерфейс** — `TextAnalyzer.exe` из релиза; из исходников — `run.bat` или
`.venv\Scripts\python -m textanalyzer`.

- Тексты: вставить в редактор, «Файлы…» / «Папка…» или перетащить в окно (`.txt`, `.md`, `.docx`).
- Справа — что анализировать, метод и словарь эмоций, форматы и папка отчётов.
- «Анализировать» (F5): отчёт сохраняется в папку и открывается на вкладке «Отчёт».
- Модели загружаются при первом анализе (~15 с), следующие запуски — сразу.
- Вкладка «Справка» (F1) — подробная инструкция; у всех кнопок и настроек есть всплывающие подсказки.
- Настройки окна хранятся в `%APPDATA%\TextAnalyzer\TextAnalyzer.ini` (удалите файл, чтобы сбросить).

**Командная строка** (пакетная обработка; в релизе вместо `.venv\Scripts\python -m textanalyzer` —
`TextAnalyzer-cli.exe`):

```bat
.venv\Scripts\python -m textanalyzer analyze samples -o out
.venv\Scripts\python -m textanalyzer analyze a.txt b.docx --formats html,json --emotions lexicon
.venv\Scripts\python -m textanalyzer analyze samples --lexicon manual
.venv\Scripts\python -m textanalyzer analyze --text "Как же я рад тебя видеть!"
```

Ключи: `--emotions both|model|lexicon|off`, `--lexicon nrc|manual`, `--no-morphology`, `--no-syntax`,
`--no-entities`, `--max-trees N`, `--name имя_отчёта`. Полный список — `python -m textanalyzer analyze -h`.
Словарь NRC EmoLex: `python -m textanalyzer download-nrc` (то же, что `scripts\download_nrc_lexicon.py`).

## Входные файлы

| Формат | Расширение | Что читается | Особенности |
|---|---|---|---|
| Обычный текст | `.txt`, `.text` | весь файл | кодировка определяется автоматически: UTF-8 (рекомендуется), UTF-16, Windows-1251, KOI8-R, CP866 |
| Markdown | `.md` | весь файл как обычный текст | разметка (`#`, `*`, ссылки) не удаляется и попадает в анализ |
| Документ Word | `.docx` | абзацы основного текста | таблицы, колонтитулы, сноски, надписи и картинки не читаются |
| Таблица | `.csv`, `.tsv`, `.xlsx` | выбранный столбец: каждая строка — отдельный текст | см. «Таблицы CSV и Excel» |

- **Один файл — один текст** (если в нём нет разделителей, см. ниже): свой раздел в отчёте; для
  нескольких текстов добавляются сводка и сравнение. Название текста — имя файла без расширения.
- **Папка** — берутся все `.txt`, `.md`, `.docx`, включая подпапки; другие файлы и временные файлы Word (`~$…`) пропускаются.
- **Пустые файлы** не добавляются.
- **Не поддерживаются** `.doc`, `.xls`, `.pdf`, `.rtf`, `.odt`, `.ods`, `.html`, `.epub`, `.fb2`, сканы — программа
  не возьмёт такой файл и объяснит, как его преобразовать (сохранить как `.docx`/`.xlsx`/`.txt` или скопировать текст).

### Таблицы CSV и Excel

Каждая строка таблицы — отдельный текст. При добавлении таблицы в окне открывается импорт:
лист (для Excel), «первая строка — заголовки», **столбец с текстом** и **столбец с названием**
(необязательно; без него тексты называются «файл — строка 17») и предпросмотр. Столбцы угадываются:
текст — самые длинные значения, название — заголовок вроде «Название», «Товар», «Автор», «ID».
Выбор можно поменять позже кнопкой «Столбцы…»; при добавлении нескольких таблиц его можно
применить ко всем (столбцы ищутся по заголовкам).

- CSV: кодировка и разделитель (`;` `,` табуляция `|`) определяются автоматически, многострочные ячейки
  в кавычках читаются; если ровных столбцов нет — файл считается одним столбцом (строка файла = текст).
- Excel: значения ячеек, для формул — последний вычисленный результат.
- В командной строке: `--text-column "Отзыв" --title-column "Товар"` (заголовок, буква или номер с 1),
  `--title-column none`, `--sheet "Лист2"`, `--no-header`.

**Большие наборы текстов.** Подробные разделы (графики, таблицы, деревья) строятся для первых
30 текстов — настройка «Подробных разделов» / `--detailed N`. Остальные в HTML показаны компактно
(строка со шкалой эмоций, раскрывается в разбор предложений), в DOCX — только в сводной таблице;
JSON содержит всё. Для нескольких текстов отчёт начинается со сводной таблицы (в HTML сортируется)
и раздела «Все тексты вместе». Таблица из 300 коротких отзывов со всеми тремя отчётами — около минуты.

### Несколько текстов в одном файле

Строка, начинающаяся с разделителя (по умолчанию `===`), начинает новый текст; слова после
разделителя становятся названием текста в отчёте:

```
=== Отзыв 1
Заказ пришёл вовремя, всё понравилось.
=== Отзыв 2
Ждал три недели, коробка была разбита.
===
Текст без названия (получит имя «файл — 3»).
```

- Работает и для файлов, и для текста, вставленного в редактор; файл без разделителей — один текст.
- В окне: галочка «Несколько текстов в одном файле» и поле «Разделитель» под списком текстов;
  в списке видно, на сколько текстов разделится элемент.
- В командной строке: `--separator "***"` — другой разделитель, `--no-split` — не делить.
- Пример: [samples/05_отзывы_несколько.txt](samples/05_отзывы_несколько.txt).
- В Markdown строка `===` под заголовком — разметка заголовка, она тоже разделит текст.

Требования к тексту: русский язык; **перевод строки — граница предложения** (текст из PDF с
переносами посреди предложений нужно склеить); абзацы лучше разделять пустой строкой.
Скорость — около 2000 слов в секунду (10 тыс. слов ≈ 5 с анализа + несколько секунд на отчёты).

## Что в отчёте

| Раздел | Содержание |
|---|---|
| Общая статистика | слова, предложения, абзацы, средние длины, MATTR, лексическая плотность |
| Эмоции | профиль текста (радость, грусть, удивление, страх, гнев, нейтрально), динамика по предложениям, эмоциональная лексика с учётом отрицаний и усилителей |
| Морфология | части речи (причастие и деепричастие отдельно), грамматические категории, частотный словарь, слова вне словаря, разбор каждого слова |
| Синтаксис | грамматические основы, цель высказывания, простое/сложное (ССП, СПП, БСП), причастные и деепричастные обороты, однородные члены, дерево зависимостей |
| Сущности | персоны, места, организации (в именительном падеже) |

Для набора текстов — сводная таблица и сравнение эмоциональных профилей.

Разделы HTML-отчёта сворачиваются щелчком по заголовку (тексты и подразделы внутри них); вверху есть
кнопки «Развернуть всё», «Свернуть всё», «Свернуть подразделы». В DOCX разделы — заголовки Word,
которые сворачиваются штатно.

## Как это устроено

- **spaCy `ru_core_news_md`** — токенизация, части речи, признаки, синтаксис (Universal Dependencies), NER.
- **pymorphy3** — исправление лемм, где лемматизатор spaCy ошибается; нормализация имён
  («Ирине Соколовой» → «Ирина Соколова»); страховка для повелительного наклонения.
- **`cointegrated/rubert-tiny2-cedr-emotion-detection`** — нейросетевая оценка эмоций по предложениям.
- **NRC EmoLex** (`models/nrc-emolex/lexicon_ru.json`, см. выше) или **ручной словарь**
  (`textanalyzer/nlp/data/lexicon_manual_ru.json`) — эмоциональные слова для словарного метода
  и подсветки в отчёте.
- **`textanalyzer/nlp/data/lexicon_rules_ru.json`** — усилители и ослабители (множитель веса),
  отрицания и глаголы, через которые отрицание переносится на эмоцию («не испытываю страха»).

Члены предложения выводятся из UD-разметки эвристически: грамматическая основа
надёжна, второстепенные члены — приблизительно. Ошибки самого парсера (например,
на обращениях и неполных предложениях) переходят в отчёт.

## Структура

```
textanalyzer/
  cli.py, __main__.py   точка входа (GUI по умолчанию, analyze — пакетный режим)
  config.py             пути и настройки анализа
  loaders.py            чтение .txt/.md/.docx с определением кодировки, разделитель текстов
  tables.py             таблицы CSV/XLSX: чтение, выбор столбцов, строки -> тексты
  nlp/                  pipeline, morphology, syntax, stats, emotions, labels, models,
                        nrc (сборка русского словаря из архива NRC EmoLex)
  report/               html (+templates/, графики на HTML/SVG), docx (+charts на matplotlib),
                        common (сводка по набору текстов), экспорт JSON
  gui/                  главное окно (PySide6), окно импорта таблицы, справка, фоновый поток анализа
scripts/download_models.py        модель эмоций -> models/
scripts/download_nrc_lexicon.py   словарь NRC EmoLex -> models/nrc-emolex/
packaging/              сборка .exe / .app (PyInstaller), значок, README для пользователя
.github/workflows/      сборка для Windows и macOS на GitHub Actions
samples/                тестовые тексты
tests/                  pytest
.run/                   конфигурации запуска PyCharm
```
